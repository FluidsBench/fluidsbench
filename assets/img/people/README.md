## Licensing and permission

No explicit open-reuse licence was found on these profile pages or image files. An image appearing on an institutional profile establishes provenance but does not by itself grant permission to republish it. Institutional copyright and website terms may apply. FluidsBench should retain each organiser's approval to display their portrait and should replace or remove a portrait if its subject or rights holder requests it. The files are stored locally rather than hotlinked so the site does not depend on an external image URL remaining stable.

`daniel-leibovici.jpg` and especially `richard-dwight.jpg` are relatively small source images. If sharper originals become available with permission, replace the local files and update this record.
