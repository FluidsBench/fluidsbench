Before you begin

A few useful details.

Questions about your submission?
Talk to the community →

When will I be able to see the results?

The first official leaderboard is planned for 24 November 2026. It will bring together reviewed submissions received by the first-release cutoff. Submissions continue afterwards, with later results appearing in subsequent releases.

Are submissions confidential before launch?

No. Submissions and their review are public on GitHub. The official website rankings will be published together on the release date.

Do I need to run every dataset?

No. Start with one open dataset and one supported split. Follow that dataset's guide for the complete set of required evaluation cases.

Do I have to publish my model or source code?

Code and model artifacts are optional. Every submission needs the required result package and evaluation evidence. See what FluidsBench validates.
